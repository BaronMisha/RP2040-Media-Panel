# RP2040 Media Panel Companion

Windows-компаньон для протокола `RPMP1`. Он проверяет соединение, читает
состояние устройства, получает метаданные и обложку из Windows Media Session
и передаёт их панели.

## Требования

- Windows 10 версии 2004 или новее;
- .NET 10 SDK;
- прошивка с USB Serial protocol v1;
- закрытый Serial Monitor перед запуском.

## Автономный режим

Самый простой запуск — двойной щелчок по
`Rp2040MediaPanel.Companion.exe`. Запуск без аргументов автоматически включает
фоновый медиарежим, автопоиск панели, значок в системном трее и открывает
минимальное окно управления. В окне можно просматривать автоматически
обновляемый журнал и включать или отключать автозагрузку.

Кнопка **Скрыть** и закрытие окна оставляют компаньон работающим в системном
трее. Открыть окно снова можно двойным щелчком по значку или пунктом
**Открыть** в его контекстном меню. Запуск с `--background`, в том числе из
автозагрузки, не показывает окно автоматически.

Запуск с автоматическим поиском совместимой панели:

```powershell
.\Rp2040MediaPanel.Companion.exe --media-session
```

Компаньон перебирает доступные COM-порты, отправляет `HELLO` и подключается
только к устройству `YD-RP2040` с дисплеем `ILI9341` 240×320 и протоколом
`RPMP1`. Если задан `preferredPort` и этот порт временно отсутствует, поиск
продолжается по остальным портам. После отключения USB соединение
восстанавливается автоматически.

Фоновый запуск без консольного окна:

```powershell
Start-Process .\Rp2040MediaPanel.Companion.exe -ArgumentList '--background'
```

После запуска появляется значок `RP2040 Media Panel` в области уведомлений
Windows. Если значок скрыт, нажмите стрелку `^` рядом с часами. Щёлкните по
значку правой кнопкой мыши и выберите **Отключить и выйти**: компаньон отправит
панели `RELEASE`, вернёт её к GIF-заставке и завершится.

Остановить фоновый экземпляр и вернуть панель к GIF-заставке:

```powershell
.\Rp2040MediaPanel.Companion.exe --stop-background
```

Одновременно работает только один экземпляр медиакомпаньона. Журнал фонового
режима записывается в:

```text
%LOCALAPPDATA%\RP2040MediaPanel\companion.log
```

При первом запуске автоматически создаётся конфигурация:

```text
%LOCALAPPDATA%\RP2040MediaPanel\config.json
```

Пример:

```json
{
  "preferredPort": null,
  "lyricsEnabled": true
}
```

`preferredPort` можно заменить на `"COM20"`. Параметр командной строки
`--port COM20` имеет более высокий приоритет. Для временного отключения
сетевого поиска текста используется `--no-lyrics`.

Установить или удалить автозапуск для текущего пользователя Windows:

```powershell
.\Rp2040MediaPanel.Companion.exe --install-autostart
.\Rp2040MediaPanel.Companion.exe --remove-autostart
```

Установка добавляет в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
запуск этого же `.exe` с параметром `--background`; права администратора не
требуются.

## Проверка передачи медиаданных

Сначала установите прошивку с командами `MEDIA`, `STATE` и `RELEASE`, затем:

```powershell
C:\Users\baron\.dotnet\dotnet.exe run --project companion\Rp2040MediaPanel.Companion -c Release --no-build -- --port COM20 --simulate
```

На дисплее должны появиться:

- название `PC Link Test`;
- исполнитель `Windows Companion`;
- альбом `RPMP | Transport`;
- статус `ВОСПРОИЗВЕДЕНИЕ С ПК`;
- громкость 80%;
- движущийся progress bar.

Приложение отправляет `STATE` раз в секунду, а прошивка плавно двигает позицию
локально. При `Ctrl+C` отправляется `RELEASE` и возвращается GIF-заставка. При
аварийном закрытии или потере связи она восстанавливается через пять секунд.

## Windows Media Session

Запусти музыку в приложении, которое публикует системную медиасессию Windows,
и выполни:

```powershell
C:\Users\baron\.dotnet\dotnet.exe run --project companion\Rp2040MediaPanel.Companion -c Release --no-build -- --port COM20 --media-session
```

Компаньон использует текущую сессию, выбранную Windows, и передаёт метаданные,
позицию, состояние и Thumbnail. Обложка центрируется, масштабируется до
160×160, переводится в RGB565 и передаётся только при смене трека. Проверить:

1. название, исполнитель и альбом соответствуют текущему треку;
2. на экране отображается реальная обложка;
3. progress соответствует позиции;
4. пауза меняет надпись на `ПАУЗА`;
5. следующий трек обновляет метаданные и обложку;
6. закрытие плеера возвращает GIF-заставку;
7. `Ctrl+C` отправляет `RELEASE`.

Во время передачи консоль показывает прогресс `[COVER]` от 10% до 100%, а
после завершения — фактическое время и скорость.
Если плеер не сообщает `AlbumTitle`, вместо пустой строки используется
отличающийся от исполнителя `Subtitle`, а затем `Альбом не указан`.
Идентификатор приложения (например, `ru.yandex.desktop.music`) на экран не
выводится. Если `Thumbnail` отсутствует, панель показывает процедурный
placeholder.

Компаньон читает master volume текущего мультимедийного устройства вывода
Windows и обновляет панель раз в секунду. При включённом mute отображается
`ГРОМ. 0%`, а если Core Audio временно недоступен — `ГРОМ. --`.

### Синхронизированный текст

В режиме `--media-session` компаньон автоматически ищет синхронизированный
текст по названию и исполнителю через публичный API LRCLIB. Сетевой запрос
выполняется асинхронно и не останавливает передачу состояния или обложки.
Для поиска метаданные текущего трека отправляются на `lrclib.net`.

Найденный LRC сохраняется в:

```text
%LOCALAPPDATA%\RP2040MediaPanel\Lyrics\<media_id>.lrc
```

При следующем запуске этого трека используется локальный файл. В консоли
появляются строки:

```text
[LYRICS] Найден синхронизированный текст: ... строк.
[LYRICS] Строка ... мс передана.
```

Если синхронизированный текст не найден, сеть недоступна или LRC повреждён,
панель продолжает показывать обложку. Временные ответы `408`, `429` и все
серверные `5xx`, включая Cloudflare `521`, повторяются для текущего трека с
паузами 15, 30, 60 и затем 120 секунд; `Retry-After` сервера имеет приоритет.
При наличии текста компаньон передаёт только окно previous/current/next, а
плавную подсветку рассчитывает RP2040.

Кириллица отображается пропорциональным Roboto Condensed Medium. Генератор
учитывает реальные границы каждого глифа, поэтому буквы не накладываются и не
получают искусственно увеличенные интервалы. Контуры растеризуются нативным
монохромным hinting FreeType без пороговой обработки сглаженной маски. Размер
текста автоматически уменьшается до доступного, а слишком длинная строка
завершается многоточием.

## Изменения companion 2.0.0

- Сначала согласуется `RPMP2`; при отсутствии поддержки автоматически используется `RPMP1`.
- В `RPMP2` обложка 160×160 передаётся одним бинарным RGB565-потоком с CRC32, без 54 Base64-команд и подтверждений каждого блока.
- Thumbnail запрашивается с задержкой 250 мс и повторно проверяется в течение первых 10 секунд трека. Временное отсутствие обложки больше не фиксируется до перезапуска трека.
- Ошибки доставки повторяются через 0,5 с, 2 с, 5 с и далее каждые 30 секунд без необратимой остановки.
- Временные ошибки LRCLIB не кэшируются как постоянное отсутствие текста; кэш успешных результатов ограничен 256 треками.
- Фоновый журнал содержит версию и путь процесса, ротируется при 2 МиБ и хранит до пяти архивов.

Интерфейс прошивки показывает вращающийся диск с обложкой. Без синхронизированного текста диск имеет диаметр 160 пикселей; при появлении текста он за 300 мс уменьшается, смещается влево и продолжает вращаться, а справа отображаются предыдущая, текущая и следующая строки. На паузе вращение останавливается.
